## Decisions

- **Runtime i18n instead of Angular's build-time `$localize`.** Users switch language without a reload and one build
  serves both locales; a small signal-based service avoids a new dependency.
- **`ng-openapi-gen` (MIT) for clients.** Angular-native, tree-shakable functions, no Java needed in CI.
- **Shared libraries are source libraries** consumed through tsconfig paths, not published packages.
- **Placeholders until W-01:** `/bff/user` response shape (`SessionUser`), `/bff/*` endpoints, `X-CSRF` header and the
  `/pdp` prefix the BFF uses for the PDP.
